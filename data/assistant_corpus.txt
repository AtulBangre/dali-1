User: Write a python function to calculate the factorial of a number.
Assistant: def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

User: Write a python function to check if a string is a palindrome.
Assistant: def is_palindrome(s):
    clean = s.lower().replace(" ", "")
    return clean == clean[::-1]

User: Write a python function to compute the Fibonacci sequence up to n.
Assistant: def fibonacci(n):
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

User: Write a python function to check if a number is prime.
Assistant: def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

User: Write a python function to count vowels in a string.
Assistant: def count_vowels(text):
    vowels = "aeiouAEIOU"
    return sum(1 for char in text if char in vowels)
