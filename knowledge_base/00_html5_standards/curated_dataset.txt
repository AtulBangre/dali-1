How do native HTML5 `<details>`, `<summary>`, and `<dialog>` elements work without JavaScript?
<|assistant|>
### 1. Native Accordion Dropdown (`<details>` & `<summary>`):
```html
<details>
    <summary>How does DALI-1 achieve sub-quadratic O(T) latency?</summary>
    <p>By replacing quadratic self-attention with compact predictive recurrence and a bounded key-value memory bank updated via a learned selective gate.</p>
</details>
```
The browser natively handles toggle state, keyboard accessibility (`Enter`/`Space`), and ARIA expansion attributes automatically.

### 2. Native Modal Dialog (`<dialog>`):
```html
<dialog id="auth-modal">
    <form method="dialog">
        <h2>Sign In</h2>
        <input type="text" placeholder="Username" required>
        <button type="submit">Confirm</button>
        <button type="button" onclick="document.getElementById('auth-modal').close()">Cancel</button>
    </form>
</dialog>

<button onclick="document.getElementById('auth-modal').showModal()">Open Dialog</button>
```
`dialog.showModal()` automatically creates a top-layer backdrop (`::backdrop`) and traps focus inside the modal for accessibility.
