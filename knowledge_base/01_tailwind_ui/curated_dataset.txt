What are the fundamental Tailwind CSS responsive breakpoints and how do you use mobile-first design?
<|assistant|>
### Tailwind CSS Mobile-First Breakpoints:
Tailwind uses mobile-first design. Unprefixed classes apply to all screens by default; breakpoint prefixes trigger at the minimum screen width:

1. `sm:` $\ge$ 640px (Large phones / small tablets)
2. `md:` $\ge$ 768px (Tablets)
3. `lg:` $\ge$ 1024px (Laptops & desktops)
4. `xl:` $\ge$ 1280px (Large desktop monitors)
5. `2xl:` $\ge$ 1536px (Ultra-wide screens)

### Example Pattern:
```html
<!-- Stacks vertically on mobile (w-full), 2-cols on tablet (md:w-1/2), 3-cols on desktop (lg:w-1/3) -->
<div class="w-full md:w-1/2 lg:w-1/3 p-4">
    <div class="text-sm md:text-base lg:text-lg text-slate-800">
        Responsive Content
    </div>
</div>
```
Always design for mobile first, then layer on `md:` and `lg:` classes to expand layout on wider screens.
