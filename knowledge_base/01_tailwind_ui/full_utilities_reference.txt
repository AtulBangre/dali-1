Explain Tailwind CSS State Modifiers, Group/Peer selectors, and Dark Mode configuration.
<|assistant|>
### 1. Pseudo-Class State Modifiers:
- `hover:`: Triggers on mouse hover (`hover:bg-indigo-600`, `hover:shadow-lg`, `hover:-translate-y-1`)
- `focus:` & `focus-visible:`: Triggers on keyboard/mouse focus (`focus:ring-2 focus:ring-indigo-500`)
- `active:`: Triggers on mouse press (`active:scale-95`)
- `disabled:`: Triggers on disabled inputs/buttons (`disabled:opacity-50 disabled:cursor-not-allowed`)

### 2. Group & Peer Modifiers:
- **Group (Parent to Child):** Add `group` on parent, and `group-hover:text-indigo-600` on children. Hovering the parent triggers styles on the child.
- **Peer (Sibling to Sibling):** Add `peer` on an input, and `peer-checked:block` or `peer-focus:border-indigo-600` on adjacent siblings.

### 3. Dark Mode Configuration:
In `tailwind.config.js`:
```javascript
module.exports = {
  darkMode: 'class', // or 'media'
  content: ['./src/**/*.{html,js,jsx,tsx}'],
  theme: {
    extend: {
      colors: {
        brand: '#4f46e5'
      }
    }
  }
}
```
In HTML:
```html
<div class="bg-white text-slate-900 dark:bg-slate-900 dark:text-white">
  Adapts automatically when 'dark' class is present on &lt;html&gt;.
</div>
```
