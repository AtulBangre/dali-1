# Module 3: MERN Stack Backend (Node.js, Express & MongoDB)

> **Objective:** Master Node.js runtime, Express REST APIs, JWT authentication, and MongoDB/Mongoose database pipelines.

## 1. Key Topics & Standards
1. **Node.js & Express Architecture:**
   - Event loop and non-blocking I/O.
   - Routing, controllers, and middleware chains (`(req, res, next) => ...`).
   - Global Error Handling middleware.
   - CORS & Security Headers (Helmet, rate-limiting).
2. **MongoDB & Mongoose:**
   - Schema definitions with timestamps, validation, and indexes.
   - CRUD Operations: `find`, `findByIdAndUpdate`, `deleteOne`.
   - Relationships: `populate` vs Aggregation pipelines (`$lookup`, `$match`, `$group`).
3. **Authentication & Authorization:**
   - Password hashing with `bcryptjs`.
   - JWT token generation & Bearer verification middleware.
   - Role-Based Access Control (Admin vs User).
