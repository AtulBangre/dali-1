# Module 5: DevOps, Containers & Deployment (Docker & Git)

> **Objective:** Master containerization with Docker, multi-stage production builds, and advanced Git version control workflows.

## 1. Key Topics & Standards
1. **Docker Containerization:**
   - Writing clean, secure Dockerfiles (`FROM`, `WORKDIR`, `COPY`, `RUN`, `CMD`).
   - Multi-stage builds for minimal production image sizes.
   - Leveraging Docker layer caching (`package.json` before `COPY . .`).
   - `docker-compose.yml` for multi-service local development (App + DB + Redis).
2. **Advanced Git Workflows:**
   - Interactive rebase (`git rebase -i`).
   - Merge conflict resolution strategies.
   - Branching models (Feature branching, PR workflow).
   - Clean commit conventions (Conventional Commits: `feat:`, `fix:`, `refactor:`).
